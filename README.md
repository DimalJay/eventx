# Event Name
============
EventX-Event Management System

## Project Description
----------------------
EventX is an event management system that allows users to create, manage, and attend events. It provides a platform for event organizers to promote their events and for attendees to discover and register for events of their interest. The system includes features such as event creation, ticketing, attendee management, and event promotion.
